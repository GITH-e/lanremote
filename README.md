# 近控 LanRemote

无需注册账号、无需云服务器的 Android → Windows 局域网控制软件。当前为 **0.2.0 测试版**，适合个人电脑在可信局域网内使用。

0.2.0 更新：默认启用虚拟鼠标/触摸板，在画面上显示蓝色光标箭头；滑动相对移动、轻点左键、连点双击、长按拖拽、双指滚动，并提供独立左右键、滚轮按钮及速度调节。可切换到原来的点按模式。请同时更新电脑 EXE 和手机 APK。

0.1.1 更新：手机先检查电脑连通性，连接失败时提示网络/防火墙原因，不再提前要求等待电脑弹窗；电脑记录配对请求并将确认窗口置前。升级时请同时更新 EXE 和 APK，APK 可覆盖安装。

已配置好防火墙的电脑：先关闭旧电脑端，再将新 EXE 覆盖到原来的文件位置，以保留针对该路径的规则；移到另一个目录可能需要重新配置。

## 使用方法

1. 电脑运行 `dist/LanRemote-Windows.exe`。保持窗口打开；Windows 防火墙若询问访问权限，允许**专用网络**。
2. 安卓手机安装 `dist/LanRemote-Android.apk`，打开“近控”。要求 Android 8.0 或以上。
3. 手机与电脑连接同一 Wi-Fi，也可以让电脑连接手机热点。路由器不需要接通互联网；不要使用开启客户端隔离的访客网络。
4. 在手机填写电脑窗口中的 **IPv4 地址:8765**、**8 位配对码**及 **24 位证书校验码**。校验码可忽略空格和大小写。
5. 点击连接，再在电脑弹窗点击“允许连接”。每次电脑端启动配对码会变化；手机仅记住地址和校验码，不保存会话令牌。

如果电脑显示多个地址，应选择与手机同一网段的地址；VPN、虚拟机网卡地址通常不是要使用的地址。连接失败时先检查两端是否能在局域网互通、电脑专用网络防火墙是否允许 TCP 8765。

**手机等待连接、电脑没有弹窗：**先看电脑日志是否收到配对请求。如果没有，请检查实际 Wi-Fi 网卡地址，以及 Windows 当前 Wi-Fi 网络是否被标记为“公用网络”。仅允许“专用网络”的规则在公用网络不会生效。对可信的家庭网络，可以在 Windows 设置中将该 Wi-Fi 改为专用网络；也可以让管理员为近控 EXE 配置当前网络下仅允许本地子网 TCP 8765 的入站规则。已有的显式阻止规则会优先于允许规则，需要针对该 EXE 一并调整。不要关闭整个防火墙。

## 功能

- **实时屏幕**：查看主显示器，按比例缩放到最大 1280 像素，JPEG 轮询，理想条件下约 5 帧/秒。实际流畅度取决于电脑与无线网络。
- **虚拟鼠标（默认）**：把画面当触摸板，手指滑动相对移动蓝色光标；抬手再滑动会从原光标位置继续，不会跳到手指落点。轻点左键，连续轻点两次双击，静止长按约半秒后移动可拖拽，松手释放；也可先勾选“拖拽”再滑动。拖拽期间光标为橙色。双指上下滑动滚动页面；独立“左键”“右键”“滚↑”“滚↓”按钮在当前光标位置操作。
- **速度与模式**：拖动“速度”滑杆调整灵敏度（0.5–3 倍），点击“触摸板/点按”切换。点按模式按画面绝对位置定位，滑动不会自动误点。横屏保留鼠标按钮、模式与速度控件。
- **光标同步**：连接时读取电脑实际光标位置；手机无操作时跟随电脑鼠标。在手机滑动期间先显示预测位置，待电脑响应后同步；画面本身仍为约 5 帧/秒。仅支持主显示器，箭头是位置标记，不模拟 Windows 文本光标等不同形状。
- **拖拽释放**：正常松手、双指切换、切后台或旋转屏幕会释放拖拽；异常断线时，电脑在最后一次指令后约 3 秒自动释放。保持手指按住时会续发位置，避免长时间静止拖拽被提前释放。
- **手机 → 电脑文件**：“发送文件”通过系统选择器选择，可多选；文件保存到 `%LOCALAPPDATA%\LanRemote\收到的文件`。电脑端可一键打开目录。文件名加入随机前缀，避免覆盖同名文件。单个上传文件上限 2 GB。
- **电脑 → 手机文件**：电脑端点击“选择文件发给手机”；手机点击“电脑文件”，选文件和保存位置。只允许下载电脑端明确加入分享列表的文件，不开放整个磁盘。
- **微信文件 → 电脑**：在微信打开已下载文件，寻找“用其他应用打开”或系统分享入口，选择“近控”，再点“发送待传文件到电脑”。支持 Android `ACTION_SEND`、`ACTION_SEND_MULTIPLE` 和 `content://` 的 `ACTION_VIEW`。微信某些文件或版本不提供系统分享；可先保存到手机下载目录，再在近控选择文件。
- **文字剪贴板**：点击“立即同步剪贴板”，或勾选“前台自动同步文字剪贴板”。手机新增的非空文字优先发给电脑；手机文字未变化时从电脑拉取。首次同步若手机已有非空文字，会以手机文字为准。双方同时修改时手机优先。不支持图片、文件剪贴板。

Android 10 及以上限制后台读取剪贴板，因此自动同步仅在近控处于前台且有焦点时进行。切回近控后恢复。应用不会申请无障碍、Root 或读取日志权限来绕过系统限制。

微信分享文件可能先临时缓存到应用私有缓存目录以获得准确长度，因此手机需要相应剩余空间。成功或失败后删除临时副本；失败的待传列表保留供重试。进程被系统杀死后可能需要重新分享原文件。文件传输期间建议保持近控前台。

## 连接与安全边界

- TLS 1.2 及以上加密，手机使用电脑显示的 SHA-256 证书指纹前 96 位固定验证电脑身份。
- 正确配对码之外，还须电脑端点击允许；每分钟最多 5 次配对尝试。每次仅保留一个有效手机会话，有效期 12 小时。
- “断开手机”立即撤销会话；关闭电脑窗口停止服务，不安装系统服务、不设置自启动。
- 软件监听 TCP 8765。不要做公网端口映射；当前版本不提供公网穿透或异地中继。
- 仅控制当前登录用户的普通桌面；不支持 UAC 安全桌面、Windows 登录/锁屏、受保护内容、多显示器切换或管理员程序的可靠操作。
- 电脑需保持开机且用户已登录，不能处于睡眠状态。
- 当前 APK 使用开发签名，EXE 未购买代码签名证书。这是本地测试构建，不是已上架的正式产品。

## 源码与构建

目录结构：

```text
desktop/       Windows 窗口、Win32 操作、TLS HTTP 服务
android/       无第三方运行依赖的原生 Java Android 应用
tests/         本地 TLS 接口集成测试
dist/          可安装文件
```

Windows 构建（Python 3.13，64 位）：

```powershell
python -m pip install --target .deps -r requirements.txt pyinstaller
.\build-windows.ps1
```

Android 构建有两种方式：

1. 用 Android Studio 打开 `android`，安装 Android SDK 35，然后 Build APK；或
2. 使用本项目脚本下载 Microsoft JDK 17 和 Google Android SDK 编译输入，直接通过 javac / D8 / aapt2 / apksigner 构建，不依赖 Gradle 下载。

```powershell
python bootstrap_android.py
.\build-android.ps1
```

首次下载构建依赖需要互联网；生成的 EXE/APK **日常运行不需要互联网**。工具仅解压到 `.tools`，不修改系统 Java/Android 安装。

运行测试：

```powershell
$env:PYTHONPATH = "$PWD\.deps"
python -m unittest discover -s tests -v
```

## 真机验收清单

- 路由器断开外网，手机关闭移动数据，两端仍能配对、查看屏幕、控制鼠标。
- 验证触控位置、横屏显示、右键、拖拽、滚轮；断开手机时无鼠标持续按住。
- 双向传输中文名称、空文件、大文件；比较源文件与目标文件 SHA-256。
- 微信文档通过系统其他应用入口分享给近控并接收。
- 前台双向复制文字；切后台停止读剪贴板，切回来继续。
- 电脑拒绝配对、错误配对码、撤销连接后均不能查看或控制。

当前自动化测试使用模拟桌面适配器检查协议与文件往返；不能代替 Android 真机、微信和 Windows 桌面操作的联合验收。
